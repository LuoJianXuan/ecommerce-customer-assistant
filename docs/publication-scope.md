# 发布范围与数据说明

本目录用于公开代码与可复现演示材料，实际发布版本以 Git 提交记录为准。

- 包含应用源码、页面、MCP 服务、测试、SQL 定义、演示知识，以及固定的合成训练/评估数据。
- 不包含实际密钥、运行数据库、原始采集问题、日志、完整备份、私人开发笔记和未审核截图。
- `.env.example` 和 `langfuse.env.example` 仅为安全模板；复制并填写本地配置后使用。
- Milvus 配套 MinIO 的 `minioadmin` 是该本地演示栈的公开默认凭据，不是个人云账户密钥；本栈不能直接作为公网部署配置使用。
- `real_clean.jsonl`、`real_labeled.jsonl` 保留 12 条已有演示回归样例的文本与标签；`orig_id` 现为公开序号，`source` 统一为 `demo_regression`，不能反向对应原始采集记录。它们不代表生产用户规模。
- 两处手机号形态的摘要/脱敏测试数据已统一替换为人工合成夹具；旧摘要评估结果不等于对新夹具重新评测。
- 运行清理脚本产生的证据和盘点进入 `tmp/`，仅在本地保存；原始 dump 提取脚本必须显式提供私有路径，输出原始问题受忽略规则保护。
- README、完整运行说明和固定日期评估入口已整理；章节目录仍保留历史工作台输出，含义见 docs/evaluation.md。已在新虚拟环境和独立新数据卷上完成本地启动验收，详见 docs/validation.md。
- 作者确认教程只提供需求与设计文档，代码按模块自行开发生成；第三方模型与依赖来源见 docs/sources.md。当前未替作者指定本项目的开源许可证。

后续仅从此独立发布目录整理公开提交，原始开发历史保持在原项目中。
