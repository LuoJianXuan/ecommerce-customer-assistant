## 本轮发现并修复

1. **[P1] 模型标签顺序可能静默错位**:仅校验 17 维不足以证明输出索引与术语表一致。加载权重后新增 `id2label` 全序硬校验,顺序不符直接拒绝服务。
2. **[P2] 只读查询与模型文件耦合**:原依赖会在分布/明细查询时构造分类器,阈值元数据损坏可能拖垮历史数据页。服务改为只在 POST 归类时延迟取得模型;数据库只读查询不初始化模型。
3. **[P2] 页面缺少待处理量**:用户只看见已归类数,无法判断是否需要手动跑批。分布接口新增同来源 `pending_questions`;batch/time 视图返回 null,避免把全局待处理量冒充批次指标。
4. **[P2] 来源筛选可静默拼错**:API 来源参数改为三值枚举,非法来源明确返回 422。
5. **[P3] 管理页窄屏导航溢出**:评估页导航允许换行;主题页表格与指标卡加入响应式布局。
